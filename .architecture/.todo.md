## Epic 5: Debouncer

- [ ] **Create `debouncer.rs` — define `Debouncer`**
      - Struct with fields: `last_seen: HashMap<PathBuf, Instant>`, `window: Duration`
      - `Debouncer::new(window_ms: u64) -> Self`

- [ ] **Implement `should_forward()` method**
      - Signature: `pub fn should_forward(&mut self, event: &FileEvent) -> bool`
      - If path not in `last_seen`: insert it, return `true`
      - If path in `last_seen` and elapsed < window: update timestamp, return `false`
      - If path in `last_seen` and elapsed >= window: update timestamp, return `true`

- [ ] **Write unit tests for `Debouncer`**
      - Test: same path sent twice with no sleep → second call returns `false`
      - Test: same path sent, then sent again after window duration → second call returns `true`
      - Test: two different paths sent immediately → both return `true`

## Epic 6: Reactor

- [ ] **Create `reactor.rs` — define `Reactor`**
      - Struct with one field: `receiver: std::sync::mpsc::Receiver<FileEvent>`
      - `Reactor::new(rx: Receiver<FileEvent>) -> Self`

- [ ] **Implement `run()` method**
      - Signature: `pub fn run(&mut self, debouncer: &mut Debouncer, dispatcher: &mut Dispatcher)`
      - Loops on `self.receiver.recv()`
      - On `Ok(event)`: passes to `debouncer.should_forward()`; if true, calls `dispatcher.dispatch()`
      - On `Err(_)`: breaks the loop (channel closed = shutdown signal)

- [ ] **Write unit test for `Reactor`**
      - Create a channel `(tx, rx)`
      - Send three events: two for the same path in rapid succession, one for a different path
      - Drop `tx` to signal shutdown
      - Run `reactor.run(...)` — assert only two events reached the dispatcher (one debounced)

## Epic 7: Dispatcher

- [ ] **Create `dispatcher.rs` — define `Dispatcher`**
      - Struct with fields: `registry: PluginRegistry`, `exec: Option<String>`
      - `Dispatcher::new(registry: PluginRegistry, exec: Option<String>) -> Self`

- [ ] **Implement `dispatch()` method**
      - Signature: `pub fn dispatch(&self, event: &FileEvent)`
      - Extracts extension from `event.path`
      - Calls `registry.find_by_extension(ext)`
      - Calls `plugin.on_event(event)` for each result

- [ ] **Implement `--exec` execution in `dispatch()`**
      - If `self.exec` is `Some(cmd)`: run `std::process::Command::new("sh").arg("-c").arg(cmd).spawn()`
      - Executed after plugin dispatch, not before
      - Does not block the Reactor loop (`.spawn()` not `.output()`)

- [ ] **Write unit tests for `Dispatcher`**
      - Test: dispatch a `.ts` event → assert the `.ts` fake plugin received it
      - Test: dispatch a `.rs` event with only a `.ts` plugin registered → assert no plugin called
      - Test: dispatch with `exec = None` → assert no process was attempted
