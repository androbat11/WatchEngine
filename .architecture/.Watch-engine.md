# WatchEngine — Architecture

```text
                          STARTUP
                             │
                             ▼
                    ┌─────────────────┐
                    │   CLI (clap)    │
                    │                 │
                    │ --typescript    │
                    │ --javascript    │
                    │ --watch <path>  │
                    │ --exec <cmd>    │
                    └────────┬────────┘
                             │
                    builds Config
                    registers Plugins
                             │
                             ▼
╔═════════════════════════════════════════════════════╗
║                      KERNEL                         ║
║                                                     ║
║   ┌─────────────────────────────────────────────┐   ║
║   │  Reactor                                    │   ║
║   │  owns Receiver<FileEvent>                   │   ║
║   │  loop { recv() → normalize → forward }      │   ║
║   └───────────────────┬─────────────────────────┘   ║
║                       │ FileEvent                   ║
║                       ▼                             ║
║   ┌─────────────────────────────────────────────┐   ║
║   │  Debouncer                                  │   ║
║   │  drops rapid duplicate events              │   ║
║   │  only forwards settled events              │   ║
║   └───────────────────┬─────────────────────────┘   ║
║                       │ settled FileEvent           ║
║                       ▼                             ║
║   ┌─────────────────────────────────────────────┐   ║
║   │  Dispatcher                                 │   ║
║   │  asks Registry: who handles .ts?            │   ║
║   │  calls plugin.on_event() for each match     │   ║
║   │  runs --exec if configured                  │   ║
║   └───────────────────┬─────────────────────────┘   ║
║                       │                             ║
║   ┌───────────────────▼─────────────────────────┐   ║
║   │  Plugin Registry                            │   ║
║   │  Vec<Box<dyn WatchPlugin>>                  │   ║
║   │  answers: which plugins match .ts ?         │   ║
║   └─────────────────────────────────────────────┘   ║
║                                                     ║
╚══════════════════════╤══════════════════════════════╝
                       │  plugin.on_event(&event)
          ┌────────────┼────────────┐
          ▼            ▼            ▼
  ┌──────────────┐ ┌──────────────┐ ┌──────────────┐
  │ TypeScript   │ │ JavaScript   │ │   Generic    │
  │ Plugin       │ │ Plugin       │ │   Plugin     │
  │              │ │              │ │              │
  │ .ts .tsx     │ │ .js .mjs     │ │     *        │
  │              │ │ .cjs         │ │              │
  │ setup():     │ │              │ │ setup():     │
  │ walkdir →    │ │ setup():     │ │ watch root   │
  │ find ts dirs │ │ walkdir →    │ │              │
  │              │ │ find js dirs │ │ on_event():  │
  │ on_event():  │ │              │ │ print event  │
  │ print event  │ │ on_event():  │ │              │
  └──────────────┘ │ print event  │ └──────────────┘
                   └──────────────┘


  OUTSIDE KERNEL (feeds events in)
  ─────────────────────────────────
  ┌─────────────────────────────────────────────────┐
  │  notify Adapter                                 │
  │                                                 │
  │  OS (FSEvents / inotify / ReadDirectoryChangesW)│
  │    │                                            │
  │    │ raw OS event                               │
  │    ▼                                            │
  │  translate to FileEvent                         │
  │    │                                            │
  │    │ Sender<FileEvent>  ──────────────────────────────► Reactor
  └─────────────────────────────────────────────────┘
```
